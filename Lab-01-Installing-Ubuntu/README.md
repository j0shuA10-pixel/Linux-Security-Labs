# Lab 01 - Installing Ubuntu

## Objective

Install Ubuntu Desktop inside Oracle VirtualBox to create a Linux environment for cybersecurity practice.

---

## Environment

Host OS:
- Windows 11

Virtualization Software:
- Oracle VirtualBox

Guest OS:
- Ubuntu 24.04 LTS

Memory Allocated:
- 4096 MB RAM

Virtual Hard Disk:
- 50 GB

---

## Installation Process

### Step 1

Downloaded Ubuntu Desktop ISO.

### Step 2

Created a new virtual machine inside Oracle VirtualBox.

### Step 3

Assigned:

- 4 GB RAM
- 2 CPUs
- 50 GB Virtual Disk

### Step 4

Mounted the Ubuntu ISO.

### Step 5

Booted the virtual machine and began installation.

---

## Problems Encountered

During installation Ubuntu repeatedly froze on a black screen after selecting **Try or Install Ubuntu**.

Several troubleshooting steps were attempted including:

- Testing Ubuntu 26.04
- Testing Ubuntu 24.04
- Adjusting VirtualBox graphics settings
- Changing video memory
- Verifying EFI settings
- Recreating the virtual machine

Further troubleshooting is ongoing.
