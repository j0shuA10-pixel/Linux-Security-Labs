# Lab 02 - Linux Navigation

## Objective

Learn basic Linux navigation, file management, and terminal commands using Ubuntu 24.04 running in Oracle VirtualBox.

---

## Environment

- Ubuntu 24.04 LTS
- Oracle VirtualBox
- Bash Terminal

---

## Commands Executed

whoami
pwd
ls
ls -la
mkdir CyberLab
cd CyberLab
touch notes.txt
nano notes.txt
cat notes.txt

## Tasks Completed

- Verified logged-in user
- Displayed current working directory
- Listed files and hidden files
- Created a new directory
- Navigated into the directory
- Created a text file
- Edited a file using Nano
- Verified file contents using cat

---

## Skills Demonstrated

- Linux Terminal
- Directory Navigation
- File Management
- Bash Commands
- Nano Text Editor
